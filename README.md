# NERO ACT Sim-to-Real

NERO七轴机械臂ACT仿真迁移研究项目，包含历史源码、视觉/标定工具、MuJoCo物理环境、训练与保护执行器、实验文档和结果摘要。

本仓库是2026-10-26从现场工作目录整理的源码快照，目标私有仓库为`wanglaoer2025/nero-act-sim2real`。

- 2K、5K、10K、20K四个检查点完整开发验收均为0/44，没有通过ACT完整抓放。

保留源码、测试、配置模板、机器人模型、第三方许可证、文档、关键结果和小型诊断日志，维持原目录结构。重复内容由Git存储层去重，历史快照目录没有合并或改写。

## 使用说明

本次归档未重写历史源码中的`/home/user/wq`、外部数据或SDK绝对路径，也未重新封存历史哈希证明。跨机器运行前，按对应子工程README准备Python/CUDA/MuJoCo/SDK，恢复所需数据、模型和本机配置，核对路径和来源。

软件验证与策略成功是不同证据。最新分支专项测试通过，不表示完整抓放通过；包含数据/检查点的预检在未恢复这些外部文件时会拒绝运行。

本次上传没有运行机械臂、CAN、ROS或夹爪控制。任何现场动作仍需对应版本的完整验证及独立现场授权。
