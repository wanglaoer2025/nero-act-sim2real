# ACT 下降对中恢复修复

沿用用户已批准的位置泛化方案，针对run17名义仿真在下降阶段姿态偏12.87°、夹爪基座先碰杯壁的问题补充离线纠正监督。当前只在仿真中工作，不构成真机动作授权。

运行时仍是原9维视觉ACT输入、20×8绝对动作和原保护协议。没有增加教师接管、运行时IK或固定夹爪命令，也没有放宽接触、限位、地板和时效条件。

## 实施与验收

1. 从run17开发轨迹的真实物理快照中选取160mm和120mm下降状态；同一来源组不跨训练和验证。新增12条局部纠正，8训练/4验证，保留原48条完整示教和6条抬升纠正。
2. 恢复完整积分状态、关节速度和真实上一夹爪提交目标，以离线教师恢复原抓取姿态并完成下降、闭爪、抬升、搬运、支撑放置、释放、退出。新数据必须通过物理结果、原前缀合同和逐点精确重放，不当作新的完整高位起点示教。
3. 新下降纠正的整段下降输入采用20Hz同步RGB和密集采样；其他示教维持run17已验证的采样、图像、物理标签和分组。原数据不改。
4. 验证全部数据及代码后，从冻结run17初始化再训练20轮，由验证集选模型。训练前声明新的独立16项，旧失败场景只作开发回归。
5. 冻结后先做名义完整闭环，明确记录是否夹稳、离桌、搬运、承托释放和退出；随后做开发16项及新独立16项。只有新结果能证明修复成效。
