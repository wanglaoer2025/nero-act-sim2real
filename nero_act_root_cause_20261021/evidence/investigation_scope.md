# 本轮根因调查

只读检查当前固定/衰减模型、原B252初始化、旧输出头与保持模型，零优化更新、不下发真机命令。保留所有已封存源码与输出。

假设与检验：

1. 缺失或错误的闭爪标签：核对名义恢复训练窗口、实际抽样次数、教师原始动作与接触余量。
2. 读出限幅阻止达到3毫米：对教师目标做逆映射往返，检查前两点可达性。
3. 运行输入或渲染不匹配：使用保存的物理快照、观测和上一命令，重建失败查询并与记录预测逐点比较。
4. 关键状态欠拟合与闭环固定点：测量精确训练窗口误差；只改变上一夹爪命令做输入敏感性检查，不改变权重。
5. 联合优化尺度或方向冲突：对真实训练批和关键恢复批分解七轴/夹爪梯度，比较普通监督、前两点、反映射和保持项；不做optimizer.step。

先排除接口和监督错误，再区分已证明的失败原因和仍需训练对照的解释。本轮不通过添加规则闭爪或放宽接触保护证明策略成功。
