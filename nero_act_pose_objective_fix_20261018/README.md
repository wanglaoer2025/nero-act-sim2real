# ACT 抓放姿态训练目标候选

run18的12条下降恢复数据和20轮训练尚未解决完整抓放：名义场景在未夹稳时出现16.87°朝向偏差，第6轴连杆碰桌；验证最佳和最后一轮在两条保留完整验证场景均0/2通过。本目录继续用户要求的仿真修复，不连接真机。

本候选保留同一66条物理示教、48训练/18验证、冻结run17初始化、9维视觉输入、20×8绝对动作及全部执行保护。唯一新的训练机制是：原关节L1之外，加入预测动作和教师动作经同一FK得到的位置/朝向差；参数不是在线任务坐标，也不参与推理动作生成。

- 位置误差以10mm为尺度。
- 朝向使用旋转矩阵的弦距离除以sqrt(2)，以1°弧度值为尺度；小角近似角度，不冒称严格测地角。
- 位置与朝向项合计乘0.05，加原L1；相同20点padding及前10点5倍权重。
- 先声明5轮有界候选实验，按验证集**总损失**选模型，避免继续仅按关节L1选取。
- 无新增网络权重，FK常量不进入state_dict；原推理类严格加载及相同输出已测试。

早期工程曾尝试TCP位置损失而未消除所有失败。本次增加的是显式朝向项，并保留实际访问状态纠正数据；仍是待检验假设，不能保证一次训练解决任务。

新测试先RED，后GREEN：FK位置和朝向对MuJoCo两个姿态误差小于1e-10、纯旋转零位置误差仍有损失及正确梯度、padding/零误差梯度有限、实际训练适配器接入且推理权重兼容。入口：`training/pose_objective.py`，日志`evidence/pose_red.log`和`pose_green.log`。

训练前实验声明：`evidence/predeclared_run19_experiment.json`。运行流水线为`evidence/run19_pipeline.py`；新独立v4测试未在run18执行，继续保持未用于训练/选模。名义场景未通过则停止扩大评估。所有成功声明必须等待冻结后的物理抓取、抬升、搬运、支撑放置、释放和退出结果。
