# 真实示教视觉适配对照：完成实验，拒绝采用B

用户要求“继续调整”，本轮在已完成的[79份真实数据适配](../nero_act_real_data_adapter_20261024/README.md)上，实际完成A/B各200次更新。B比只训练辅助头的A减少验证损失约**0.010631%**，低于预先规定的5%，因此**不采用B，保留原1a28模型**。本轮没有完整抓放评估或真机运动，不能据此声称迁移成功或泛化改善。

主要证据：[固定协议](run_03/protocol.json)、[完整结果](run_03/results.json)、[输入扰动诊断](input_intervention_diagnostic.json)、[独立复核](final-review.md)。

## 1 本轮解决的具体缺口

现有真实示教具有RGB、8维实测状态和夹爪意图，缺少当前15维策略要求的同版杯位/目标位、因果命令上下文等完整记录。把缺项填成零、仿真真值或旧坐标，会使数据看似能加载却改变实际语义。

本轮实现单独的离线辅助任务：从真实RGB和8维实测状态，预测20点“未来实测七轴状态＋原记录夹爪意图”。它不等于预测控制器实际收到的七轴目标，不重建缺失回执，也不直接产生主ACT的真实15维训练标签。

| 对照 | 训练的模块 | 保持冻结 |
|---|---|---|
| A | 独立real8辅助头，4个参数张量 | 原ACT及夹爪增量头、视觉残差层 |
| B | 相同辅助头＋视觉残差层，共8个参数张量 | 原ACT及夹爪增量头 |

视觉残差层接在原ACT的`input_proj`输出后，128→16→128通道，最后一层零初始化。零初始化时与原网络严格恒等；辅助头读取全局池化后的视觉特征和8维状态。辅助头不接入真机控制输出。代码：[bridge.py](bridge.py)、[experiment.py](experiment.py)。

原checkpoint实际是`FrozenIncrementPolicy`完整包装，包含`base` ACT主体及`head`夹爪增量头。本轮完整严格加载220个state_dict条目，没有忽略键或丢弃已训练头。原checkpoint SHA256：

```text
1a28f4fddd3095791403028b639b99f9775b91caab45c950c2d0f518955bc0f0
```

## 2 数据、训练预算与保持检查

- 真实数据沿用37 train、10 val，32 reserve不使用；训练/验证以episode分开，不宣称是位置独立留出。每条按开始、闭爪、释放等记录事件取最多10个20点窗口，实际370 train、100 val。事件仅用于离线抽样，不作为运行时输入。
- A/B相同初始辅助头、相同200×16批次顺序、各200次AdamW更新；头学习率1e−3，B残差层1e−4，无weight decay，梯度范数上限1。只评估最后一步，没有根据验证集挑权重。
- 辅助任务对前2点和后18点分别赋0.75/0.25权重，应用原padding。七轴误差和夹爪意图误差按固定尺度归一化，保持标签原语义。
- 原15维保持资料覆盖5条完整示教、8阶段：接近、下降、闭爪、抬升、转运、放置、释放、退出。先按原视觉有效性和有限几何筛选，再每阶段取6点；前3点作特征保持，后3点作检查。得到120 rehearsal与120多阶段check，索引不重叠。
- 训练中使用投影特征保持正则；训练后另检查完整主模型动作输出。加96个历史访问接近输入，共216 check，每个检查全部20点预测。它证明这些固定输入上的预测变化，不能代替完整闭环回归。
- 当前GPU驱动不可用，采用CPU和冻结投影特征缓存，没有调整驱动。CPU提取路径与主模型投影路径最大差为0。历史96点CUDA输出与本轮CPU基线存在最大5.1460e−5 rad、2.0196e−6 m差异，已记录并统一按CPU基线做前后对照；没有声称精确复现CUDA轨迹。

来源及抽样：[真实样本索引](run_03/real_sample_index.json)、[保持索引和CPU对照](run_03/preservation_index.json)、[固定批次](run_03/batch_order.npy)。

## 3 实际结果与采用判定

| 100个留出窗口的指标 | A：只训头 | B：头＋视觉层 |
|---|---:|---:|
| 初始辅助损失 | 0.277539015 | 0.277539015 |
| 第200步辅助损失 | 0.127269104 | 0.127255574 |
| 七轴未来状态MAE，度 | 0.564745 | 0.564778 |
| 夹爪意图MAE，毫米 | 21.2082 | 21.2162 |
| 夹爪意图二分类准确率 | 90.55% | 90.55% |
| 原15维全部20点最大七轴变化，rad | 0 | 0.0000625844 |
| 原15维全部20点最大夹爪变化，m | 0 | 0.00000151262 |

90.55%是100个窗口各20个相关目标点的**意图标签分类**，不是独立2000次实验，更不是实物抓取成功率。未来状态预测指标也不能当作命令预测误差。

预定门槛：B较A验证辅助损失至少改善5%，夹爪分类不下降，主15维全部20点最大变化不超过0.001 rad/0.001 m。实际改善为0.010631%，仅保持和分类不退化通过，整体机制门槛未通过。结果字段为`policy_adopted=false`、`full_task_passed=false`、`hardware_deployment_allowed=false`。

原模型全部参数和buffer保持不变，checkpoint文件SHA不变。A也只是辅助任务对照，不是新的可部署ACT。B的残差层不接入现有执行入口。

## 4 为什么这次没有得到有效的视觉收益

实验结束后进行了只读诊断，没有新增优化、改协议或挑权重。对100个留出窗口，使用10组固定随机排列分别错配图像、错配状态，并检查最终投影特征空间重排的影响。

| B的只读诊断 | 损失或变化 |
|---|---:|
| 原输入损失 | 0.127255574 |
| 图像样本排列后平均损失 | 0.128030808，约增加0.609% |
| 状态条件排列后平均损失 | 0.315226391，约增加147.71% |
| 特征空间重排后最大预测差 | 4.7684e−7 |

在这些探针中，新辅助头更依赖状态条件。它的逐点视觉残差后接全局池化，几乎不受最终特征格位置重排影响，没有显式保留空间顺序；对需要杯位变化驱动动作变化的目标，这个辅助任务提供的位置信号不足。这支持下一轮调整辅助读出，不能证明原ACT没有用视觉，也不能解释全部历史失败。原ACT仍使用空间特征和位置编码。

状态排列诊断保留原实测基点和目标，仅改变辅助头条件，是输入敏感性反事实，不是物理可执行轨迹。相邻窗口及20点目标相关，10次排列不是独立位置验收。[诊断脚本](diagnose.py)在实验后加入，未追改`run_03`冻结源码清单；诊断结果单独保存，A/B权重SHA保持不变。

## 5 中途两项工程修正

1. `run_01`严格加载失败：最初误按底层ACT构造，而checkpoint是完整增量包装。追踪既有模型结构后改为完整加载，新增真实checkpoint和嵌套hook回归测试。该次0更新，保留[失败记录](run_01/failure.json)。
2. `run_02`保持资料被原加载器拒绝：先按阶段直接均匀取点会选中原先无效的视觉行，240点中176点无效。新增回归后先过滤原有效性再抽样，没有放宽schema或补真值。该次0更新，保留[失败记录](run_02/failure.json)。

因此实际预算是`run_03`的A200＋B200，共400次新模块更新；原模型更新为0。没有暗中重复训练或扩大预算。

## 7 下一步调整方向与尚存缺口

下一轮建议优先把辅助头改为**保留特征空间位置的读出**，再与本轮全局池化头做同数据、同预算对照。先检查相同姿态、不同画面或杯位时，预测是否按正确方向变化，同时保留多阶段主模型检查。不能仅因训练损失降低就增加预算或部署。

这需要新一轮验证，本轮没有执行额外更新。真实15维几何/命令记录缺口、未训练位置完整闭环、TCP和相机独立验收、实时命令时效等问题仍在；空间读出改动不能替代这些检查。没有开启ROS/CAN，也没有下发真机指令。
