本目录保留用户“修正策略”这一轮的离线修正和验证。真实机械臂没有运动；尚不能据此批准实机抓放。

## 已定位和修正的问题

1. **新标定没有进入旧训练分布。** 旧267份视觉数据沿用原相机外参。第一轮重新生成新标定下的物理示教和图像，并训练固定候选，使三个开发场景都进入抓取；原来的约74厘米漂移不应归因于单纯闭爪训练不足。
2. **部分遮挡被当成多个蓝色目标。** 同一蓝卡被杯子遮成两块。观察器保留当前RGB像素，用名义100毫米正方形的尺寸、边界和可见遮挡物检查。松爪时角点继续被遮挡，故补充“三条连续可见直边各支持至少24毫米”的通道；不使用上一帧坐标、阶段真值或物体真值补输入。完全遮挡仍拒绝。
3. **已有微接触被误当作新增下穿。** 原中心失败诊断中，当前名义附着杯底为−37.739微米，ACT两个目标杯底为−27.071/+2.165微米，TCP分别向上11.637/39.590微米。因此此前把这一处解释为“策略向下”不准确。只在离线MuJoCo、稳定双边夹持且仍受桌面支撑、未离桌、无异常接触、现有名义重叠≤100微米时允许逐个扫掠采样严格向上脱离。原−1微米地板阈值保留；加深重叠、普通下降、缺失支撑、已离桌、超过限度均拒绝。100微米不是实测TCP或真实桌面误差界。
4. **结果说明过度概括。** 本接触补丁不生成或改写ACT目标，但原有接触时的机械臂保持、抓取前夹爪保持仍然存在。最终结果分别记录这两类事实，不再笼统声称整个执行过程从未改写目标。

所有评估前后检查实际导入的代码、模型、协议和几何资产哈希。仿真确认事件不是现场人员的真实确认；起点95毫米张爪也只是仿真假设，未在真机执行。本轮没有重启ROS/CAN或下发硬件命令。新手眼仍是候选、夹持TCP仍为名义值，因此真实部署标志继续为false。少量场景通过也不等于±20毫米泛化或实机验收通过。
