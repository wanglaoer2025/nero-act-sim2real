本目录为第三次受控修正，仅MuJoCo离线验证，不发送真机命令。复用第二次修复冻结的15维ACT夹爪微调模型，未新增训练或手工控制动作。

前两次结果保留：全网采样修复重训在闭爪前接触失败；仅夹爪微调已建立稳定双侧接触，但1777点时被持杯桌面保护拒绝，未抬升。

## 本次定位到的保护器问题

旧模型使用初始源位建立持杯坐标；闭爪后杯子实际已偏移约8.48毫米，并且仍由桌面承托，不能当作完全刚性附着。旧模型认为当前杯底−43.6微米，而当前物理几何约−7.84微米；原第一条预测实际上向上约31微米，最初“向下”解释已更正。[第二次诊断](../nero_act_visual_gripper_fix_20261019/evidence/attempt2_failure_diagnosis.json)。

修正使用当前物理杯体与法兰的配对位姿，仅作为仿真安全几何：首次离桌前允许桌面承托下的夹持柔顺，观察到离桌后永久冻结相对位姿；落桌后也不重新绑定。查询之间、动作前缀及人工确认等待中的物理步骤均锁存离桌，避免短暂离桌再落桌被遗漏。策略输入仍为RGB、15维观测；不向策略输入物体真值，不改写动作目标。

原穿桌阈值−1微米、速度、夹爪力、稳定接触、滑移和3900点预算保持。完整任务判据保持。当前用模拟器已知位姿修正的是安全参考几何，不构成真实相机/TCP标定或真实持杯安全资格。
