# ACT 仿真到真机迁移可行性演示

本目录执行用户 2026-10-17 的新目标：“不一定非要达到很高的仿真水平，只想看看仿真能否将流程迁移到真机”。只做一次有人监督的完整幅度 ACT 尝试，不追加训练，不宣称鲁棒性或抓放验收通过。

## 实际迁移链路

MuJoCo 完整物理抓放示教 → ACT 训练 → 冻结 run11 权重、归一化、场景及源码 → 同一模型完整仿真复跑 → 真机 RGB 和实测关节只读 shadow → 本次 ACT_DEMO 现场授权 → 在线 ACT 分块输出真实机械臂动作 → 实测反馈和结果记录 → 恢复只读。

ACT 每次读取真实 RGB 和实测 8 维状态（7 关节弧度 + 总夹爪宽度米），输出 20×8 绝对动作块；执行不超过前 10 点后重新观测。每点间隔 50 毫秒用于连续运动，不限制完整流程总角度。YOLO 只核对杯子/蓝卡位置及结果，MoveIt 只做全机器人碰撞检查；二者不生成替代 ACT 的抓放动作。接触时存在单独标注的实测姿态安全保持，不能声称每个安全保持指令都是 ACT 原始输出。
