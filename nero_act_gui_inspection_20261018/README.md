# ACT 仿真评估记录图形回放

本窗口显示已有 ACT 仿真评估中记录的物理状态，不执行新的策略推理，不连接真机。

默认打开 run17 的 `cup_+0_+0` 实际评估记录，83.2 秒，结果为失败：出现非预期机器人／环境／杯子接触。回放在记录终点停留，不自动继续。

按 **N** 切换至 run15 历史完整抓放成功记录，176.8 秒，仅作为对照；该成功不代表 run17 通过，也不代表真机验收通过。

- **空格**：暂停／继续。
- **R**：从头重播当前记录。
- **N**：切换上述两份记录。
- 鼠标拖动、滚轮：调整视角、缩放。
- **Esc**：关闭窗口。

`record_0_proof.json` 和 `record_1_proof.json` 保存来源文件及缓存的 SHA256。由初始物理快照和记录动作重建后，两份记录的最大机器人状态误差、最终杯位置误差均为 0；显示时只加载缓存物理状态，不继续物理步进。

入口为 `view_measured_simulation.py`；`viewer_status.json` 为窗口状态，`desktop_viewer_01.log` 为启动日志。
