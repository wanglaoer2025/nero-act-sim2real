# ACT接近动作保持

已加入训练用的接近动作保持损失，完成1000步离线微调和冻结评估。**本轮没有保住接近，完整抓放仍失败**：2933点因非预期接触停止，未进入GRASP；局部机制4/6。

固定零更新基线423帧抓前RGB与15维观测，约束ACT物理读出前两点；每次额外使用8个参考样本，与原68条示教/恢复数据共同训练。参考核验、保持损失及评估使用相同GPU渲染、图像布局、逐帧查询和最终物理读出。运行时仍使用同一个ACT，原保护保持。

413项测试通过、5项跳过；训练前423帧逐帧误差为0。训练后七轴均方根漂移0.961毫弧度，上一轮为0.247毫弧度；夹爪最大漂移由0.553毫米降至0.020毫米。实现通过组件验证，策略效果未通过。

[完整报告及轨迹图](evidence/results.md)包含输入配对问题、修正、训练与失败结果。[最终核验](evidence/final_verification.json)、[流水线状态](evidence/pipeline_status.json)和[训练状态](training/pilot_A/status.json)均已更新。本轮没有扩大1000步预算，没有启动真机。
