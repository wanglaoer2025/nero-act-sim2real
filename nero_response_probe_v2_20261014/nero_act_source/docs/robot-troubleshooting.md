# 本次离线修复记录

2026-10-14，适用于仿真电脑的 offline-ready 派生源码包。此文件补充本次已验证的问题；完整现场历史保存在原项目，不能把这里的软件通过记录当成实机任务验收。

## 连续夹爪动作被转换为二值

现象：模型输出米制连续总开口，旧 SafetyFilter 将其转换成 0 或 0.095 m，仿真/实机执行语义不同。
证据：中间预测0.051 m在旧迟滞逻辑中会保持全开。修正：新增显式 continuous_width 配置及 send_gripper_width，复用现有合法范围和力检查。验证：中间开度、限幅和旧默认行为回归通过，尚无实际夹持响应测量。

## 反馈领先裁剪破坏目标步长限制

现象：先按上一目标限制步长，再按新反馈限制领先距离，两次裁剪可能互相冲突。
修正：关节限位、上一目标±允许步长和当前反馈±允许领先距离求交；交集为空时报错，不继续下发。验证：反馈朝反方向变化时仍满足两种边界，偏差过大拒绝继续；原控制循环mock回归通过。

## 离线预览仍依赖SDK

现象：旧 test_joint_stream --dry-run 在打印轨迹前构造机器人。修正：完全离线分支先打印并返回；read-hardware和execute保持硬件行为。验证：屏蔽SDK时普通dry-run正常，不构造机器人。run_act_real --dry-run仍会在确认后连接/使能，不适用于只读采集。

## 记录相机输入的推理核验

新增 run_act_shadow 从已保存的NPZ读取图像与关节状态，不导入机器人包装器、不创建相机或CAN连接。按关节名重排、保留已旋转的RGB、检查时间戳及统计量。通过仅表示记录输入兼容，不能证明物体定位正确、实时反馈合格或真机抓取成功。

## 多杯训练的关节反馈基准和统计更新

v5出现偏离示范后累计关节偏移的失败。新增可选joint_residual_anchor，关节head学习相对当前观察位置的修正，统一转回绝对目标后执行相同限幅，不使用实时IK或杯子真实坐标纠偏。该改动尚需独立闭环结果判断效果，不能把它当作已证实的单一根因修复。

新尺寸/位置数据只用训练回合生成新统计。转换初始化权重的机器人状态投影和夹爪输出尺度，使其保留原有物理输入解释；之后仅清零关节head以训练残差。anchor常数保存于checkpoint配置，标准NeroActPolicy推理加载保持已学习的head，不执行初始化清零。相关数学换算、输出接口及首次初始化/再次恢复测试通过；旧配置维持默认输出行为。
