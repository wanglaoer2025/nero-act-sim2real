# ACT 夹爪限幅零梯度修复

状态：机制修复与144项检查通过；run22训练及冻结评估结束，原场景和验证42均未完成。原场景仍未修复，不连接真机。

## 因果证据

run21恢复CVAE后，验证42完整成功，但原场景仍不闭爪。其实际抓取快照为Z55.12毫米、XY误差2.64毫米、姿态误差3.45°，离线教师已验证可从这个姿态直接闭爪、抬升、搬运、放置和退出。

在同一实际输入上，原模型限幅前宽度96.5～98.4毫米，限幅后全部95毫米；对已验证闭爪目标，20个输出的梯度全0。这是该失败状态上的直接证据，不代表所有示教状态都有零梯度。详见上一工程 `../nero_act_cvae_training_fix_20261018/evidence/grasp_boundary_diagnosis.json`。

## 修正

训练时给零潜变量分支增加限幅前夹爪L1监督，权重0.05。未来动作仅作为损失标签；不送入该分支。原CVAE后验及KL0.001、姿态损失0.05保留。验证也采用无未来标签输入的零潜变量预测，计算包含辅助监督的总损失选模。

执行时仍采用原有界动作，不发送限幅前输出。没有修改接触、碰撞、时效、位移或力限制，没有手工闭爪或运行时教师接管。旧配置默认辅助权重0，仍兼容。

两段从实际冻结ACT快照开始的 `grasp_to_retreat` 恢复片段：名义场景1条训练，验证42场景1条验证。它们分别通过物理任务、前缀合同、精确重放（误差0）、来源哈希和同状态RGB审计，只计局部恢复，不计完整示教。保留原70条，总72条（训练51、验证21）。
