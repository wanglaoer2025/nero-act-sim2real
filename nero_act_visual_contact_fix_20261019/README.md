# ACT 15维视觉反馈：闭爪监督修复

本目录与原训练、原5/16验收隔离。仅离线训练及MuJoCo完整抓放评估，未启用真机。

已确认的问题：原采样器将稳定接触期的大部分夹持力建立输入过滤（36训练组中2232个>=3mm夹持间隙时刻仅保留30个）。简单恢复全部等待时刻又引入同一观测对应等待与抬升的冲突。现保留夹爪目标变化过程，并将长时间不变等待合并为最终转入抬升的代表样本；动作标签、ACT结构、优化参数及保护阈值保持。

数据与验证：48组原示教，36/12隔离；重新渲染图像池20721个有效输入。训练选择13833个不同输入，21925个加权窗口，其中540个闭爪>=3mm间隙输入。详见 evidence/selection_acceptance.json。重渲染图像池为采样超集，未改写物理动作。

评估规则：旧16项作为诊断后的配对开发回归；另16项完整数值场景在优化前固定于 evaluation/protocol.json。模型仅按验证组零潜变量损失选择。两组结果分别报告，均为旧名义标定下的仿真，不能验收真实TCP/外参精度或真机资格。

独立检查及修改：[evidence/independent_review.md](evidence/independent_review.md)、[evidence/progress.md](evidence/progress.md)。训练与完整闭环结果待本轮实际执行后补充。

20/20轮完成，验证组选择第17轮，损失0.007227。13720优化步（原模型9580步），因此不宣称等步数单因素归因。[训练完成核验](evidence/training_completion_verified.json)。
