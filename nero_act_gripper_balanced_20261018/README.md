# ACT非线性夹爪头的过渡采样对照

已批准的ACT内部非线性夹爪头保持不变；只训练新头，视觉、CVAE和七轴参数冻结。本轮仅离线训练及MuJoCo，不连接真机。

run24的57窗口拟合误差低于0.15毫米，但完整数据训练后原场景仍不闭爪；采样审计显示实际失败首态仅占3/31363个训练窗口。不能直接认定唯一原因，因此本轮单独检验监督分配。

继续使用同72条验证数据（51训练、21验证）、run21初始化、学习率0.001、辅助夹爪损失0.05和种子42。离线将闭爪首20点、释放首20点、其余合格窗口各分配三分之一；保持每组所有来源均被表示，训练/验证来源严格分开。标签只用于选训练窗口，不进入在线ACT观测。

声明20轮较小的平衡数据训练，按对应的零潜变量平衡验证损失选模型，不按原场景或独立测试选权重。新采样不是把20轮与旧5轮等同；具体窗口数、训练记录和优化步数分别留档。

先审计全部保存检查点仅新头变化，再运行原场景及验证42；原场景通过才运行开发16与预声明独立16。未改执行保护、物理条件或任务验收。
