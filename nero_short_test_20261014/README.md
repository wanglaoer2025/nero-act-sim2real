# Nero 真机首轮短测试

这是关节控制链路实测，不是 v9 策略闭环。沿用现有 SDK 包装器及反馈检查；不操作夹爪，不复位，不自动失能。没有新增测量要求。

## 运行

将整个目录复制到4090真机电脑，使用现场原有能导入 numpy 和 pyAgxArm 的 Python 环境。在本目录运行：

```bash
python run_short_test.py --dry-run
python run_short_test.py --execute
```

默认测试 J1；如该姿态下 J1 扫掠不安全，使用 `--joint-index 0..6` 选择其他关节。当前姿态是测试中心，不自动移动到模型起始姿态。

执行前，停止 ROS CAN 驱动及其他控制程序，保证 CAN 单控制者；停止驱动或切换控制时扶稳机械臂，避免失能导致下落。清理扫掠范围，空夹爪悬空，准备实体急停。两次现场确认依次为 `SINGLE_CAN` 和原入口的 `STREAM`。

命令频率20Hz，正弦周期0.5秒，幅度±0.005rad（约±0.286度），控制器速度5%。历史J1日志已有20Hz测试记录，但不证明当前状态已经通过。正常情况下约10个目标；实际数量取决于调度，必须检查CSV。0.5秒只指发送阶段，使能、连接和回位额外耗时；正常结束发送起点并等待回位，最长10秒，允许回位误差0.01rad。

异常或Ctrl-C触发原入口的电子急停。退出释放CAN但不主动失能，控制器速度5%不自动恢复。不要在程序未退出时启动ROS驱动。

## 结果

CSV保存在本目录 `logs/act_joint_stream_*.csv`。带回完整CSV及终端输出。检查缺失反馈、errors、实际频率、最大误差和回位是否完成；不能仅以退出码判断运动正常。出现异常不继续加大幅度或运行策略。

## v9策略状态

现有v9 checkpoint声明 hardware_deployment_allowed=false；当前记录姿态超出模型示范范围，尚缺实时执行调度适配。本包保留这些限制，不加载策略，也不执行预存shadow动作。该通信测试通过不等于策略迁移通过。
