# 命令增量ACT夹爪分支设计

目标：消除绝对夹爪指令约0.5～0.7毫米拟合误差吞掉每两点0.4毫米推进的闭环停滞；同时保留释放。当前仍在同一仿真内失败，不足以归因渲染或权重文件损坏。

选择依据：同一冻结ACT特征和1029训练/256验证状态上，绝对头即使直连15维仍未达0.1毫米；命令增量原型三个失败输入误差0.049～0.057毫米，后两点继续闭合约0.37毫米，两个释放输入保持打开。该对照还涉及输出初始化和损失参数化，不能证明唯一因果；它只支持开展完整离线验证。

新头以当前ACT解码特征128维＋同一次当前15维观测为条件，经64维SiLU预测20点相对上一命令的增量，tanh范围±1毫米。因果上一命令由现有观测中的实测宽度和上一命令差还原。最终仍输出绝对物理夹爪宽度，并限制于0～95毫米及当前实测宽度±9.5毫米。七轴复用原ACT输出，编码器和七轴全部冻结。没有运行时阶段真值、手工闭爪/释放或轨迹接管。

训练只监督执行前两点的增量MSE、使用原68物理数据/统计/分组/1000批顺序，普通批32，种子42，头lr3e-4，独立0.1梯度裁剪，固定1000最后检查点；无额外七轴优化与接近蒸馏梯度。冻结特征可缓存，训练和推理的特征一致性另行验证。验证集不参与更新或选模型。其余18夹爪点未验收，执行仍限定前两点。

验收保持：原3失败输入0.1毫米误差、至少0.1毫米闭合、已夹持3毫米余量；423参考七轴RMS0.1/最大0.3毫弧度；原六快照原预算全过才运行原高位3900点完整仿真。任何失败不扩大更新或放宽保护。即使开发场景完整通过，仍需偏移/延迟/真实标定和只读shadow，再另行真机执行。
