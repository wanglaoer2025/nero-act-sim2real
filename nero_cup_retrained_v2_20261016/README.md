# 当前黄色杯 ACT 重训 v2

本包包含新的抓取抬升模型、配套统计、源码、示教和冻结权重后的评估材料。任务为当前黄色杯的接近、闭爪、抬起与保持，不包含搬到蓝卡或自动放下。本轮仅进行仿真训练和验证，没有发送真机运动。

已完成80轮训练，按验证损失选中第74轮。修正保持观察窗口后，冻结模型评估 **13/16通过**；当前配对起点完成抓起与连续5秒持杯。剩余失败为持续0.5秒伺服延迟、两组独立起点/杯位扰动，故尚未取得完整真机抓取验收。

## 本轮修改

- 使用另一条 IK 姿态解，减少腕部大幅旋转，避开上轮 J7 逼近负限位的路径；仍使用最近回传的真实配对起点。
- 重新生成8条仿真物理示教，6条训练、2条验证；加入起点/杯位变化和外力扰动纠偏。全部示教通过抓取与持杯检查，保存动作在物理重放中与原状态逐点一致。
- 关节目标速度降至0.04 rad/s，每个50ms点不超过0.002 rad；夹爪每点不超过0.5mm。
- ACT预测窗口为 **20步×8维**，20步全部参与训练，近期10步加权；增加闭爪附近样本与TCP位置损失。
- 配套统计只用训练0..5计算。模型内部学习反馈残差，反归一化后的输出仍为绝对关节角和夹爪总开口，不是需要再次累加的增量。
- 增加任务完成监控：杯子抬升超过60mm、双侧夹持稳定1秒后，停止ACT新动作并冻结最后目标，继续检查连续5秒持杯。抓起后滑落仍判失败。

## 如何复核

安装 `simulation/requirements.txt` 中的依赖，在策略Python环境中运行：

```bash
python infer.py
```

精确复现所用依赖版本见 `evidence/training_environment.json`。

这只对包内历史配对图像与状态推理，输出 `logs/saved_observation`。不连接相机、ROS或CAN。实际权重为 `model/policy.ckpt`，必须配套 `model/dataset_stats.pkl` 和本包模型源码。

复现完整仿真评估：

```bash
MUJOCO_GL=egl NERO_POLICY_PYTHON=/你的环境/bin/python bash run_sim.sh
```

输出 `logs/reproduced_evaluation`，已有输出时拒绝覆盖。也可加 `--dev` 仅运行记录起点一组。图形环境需支持EGL。模型、网格和数据从包内相对路径加载；训练配置中的原始绝对路径仅作来源记录。

## 如何理解结果

最初固定总时限版本为9/16，其中4组在截止前已达到抓取条件，但5秒保持观察被截断。我们保留全部原始结果，仅对这4组补足观察；原窗口内状态和动作逐点相同（最大差为0）。修正后的13/16未更改权重、抓取阈值或到达时限。原始记录在 `evidence/evaluation_initial_window/`，逐组证明在 `evidence/hold_timing_fix.json`。

持续0.5秒延迟另行延长到120秒仍未通过，并出现仿真中意外机械臂/杯接触；这项诊断不计入16组得分。


最终原始结果、冻结权重校验值与所有失败见 `evaluation/summary.json`、`evaluation/protocol.json`。`evaluation/*.npz` 保存完整策略预测、实际施加目标、关节/夹爪反馈、杯/TCP轨迹和完成保持阶段。8个独立随机种子与2个外力种子不参与权重选择。历史实拍图重复输入仅为外观压力测试，不是真机视觉闭环。

完成监控在仿真中使用杯子位姿和接触状态来判断终止；这些信息没有输入ACT，也没有用来生成接近/抓取动作。实际机械臂上的杯子高度与夹持观察器尚未验收，不能把仿真完成判据直接当作实机已实现。

**这是重训模型包，未授予真机完整抓取执行许可。** 本包没有真机运动入口。新20步窗口不能直接替换进旧100步空中执行器；该执行器的夹爪目标跟随约束也不能直接表达接触夹持。相机/TCP/桌面接触几何仍保留未实体验证状态，原标定文件未改动。

## 文件

- `model/`：新权重、统计、配置、输入动作接口。
- `training_data/`：全部8条示教，含实际外力、完整物理状态与阶段。
- `simulation/`：便携场景XML、全部网格、延迟伺服与冻结模型评估器。
- `scene/`：实拍起点、真实/仿真对照及原标定。
- `evidence/`：训练记录、初始化变换、逐帧碰撞审计、物理重放验证。
- `tests/`：模型统计、20步接口、物理重放记录和完成保持的一致性检查。

`hardware_deployment_allowed=false` 保持不变。没有修改旧权重、限位、原始标定或现场模式配置。
