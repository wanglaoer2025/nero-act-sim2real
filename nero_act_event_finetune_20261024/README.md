9000的具体停止原因见`center_contact_diagnostic.json`：夹爪反馈73.775毫米，首目标66.233毫米，闭合差7.542毫米；首目标TCP向上0.557毫米，不能解释为没有闭爪或没有输出抬升。附着变换已冻结为airborne=true，但当前又有桌面支撑，名义刚体杯底为−23.862微米；首扫掠样本为−5.312微米，仍低于原−1微米地板，因此停止。只在离线诊断中把airborne标志假设为false，同一向上前缀可通过严格脱离检查；真实运行、保护和原结果都未改。此反事实说明支撑/离桌状态切换值得单独复核，不能据此取消保护或证明真实路径可行。

本轮对9005有阶段推进，但没有总体完整成功率提升。当前优先项是复核支撑到离桌的冻结状态、处理RELEASE后的蓝卡遮挡观测，并用真实闭环偏离状态补充恢复专家及保持约束；继续增加闭爪权重不足以覆盖这些问题。

RGB-D候选仍未通过，本轮没有接入；真实标定/TCP精度、在线视觉真机及泛化资格均未通过。单次独立复核无Critical/Important，两个Minor及边界见`final_review.md`：结束自动哈希集合缺少13项模型资产（作者已另核对全量来源未变），两个新位置协议顶层继承train元数据但未进入训练。当前证据保留，不在运行中改写封存协议。
